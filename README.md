# AIDO Multi-Omics I 5.0

Research repository for a modular biological-process approach to breast-cancer multi-omics evidence integration.

## Scope

The project studies how gene-expression, copy-number and mutation evidence can be organized at the biological-process level and interpreted alongside curated cancer-gene and protein-interaction-network resources.

## Reproducibility and availability

This public repository is under restoration. Executable source code and complete reproducibility materials have **not yet been restored or verified**. Do not treat its current contents as a validated computational package or use them for clinical decisions.

Methods and results should be interpreted using the relevant manuscript and its published or officially shared supporting material, when available. Dataset access is subject to the originating providers' licenses and conditions.

## Repository policy

Only authorized, disclosure-reviewed material will be published here: vetted research code, dependency specifications, public dataset acquisition instructions, and appropriately licensed example or aggregate outputs.

Local file-system paths, credentials, patient-level data, internal deliberations, confidential journal correspondence, and unpublished revision-stage analyses are outside the public release scope.
